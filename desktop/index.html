Releases the models after a quiet stretch; the next question reloads them. RAM comes back for other apps under pressure — a restart is the only way to see the number drop immediately.

Quiet indexing

Indexing runs quiet by default: the embedding threads are capped so the machine stays cool and usable while it works. Full speed is faster but pins every core.

Retrieval eval

Score search quality against a golden set: JSONL of queries and the paths that answer them.

HyDE retrieval

Drafts a hypothetical answer with the local model, then searches with it too — better recall on short or vague questions, at one extra model call per query.
